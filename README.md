# Student Performance Analytics System

## Project Description
This project analyzes student academic performance using Python, Pandas, and NumPy. It calculates student totals and averages, assigns grades, checks pass or fail status, and identifies top-performing students.

## Technologies Used
- Python
- Pandas
- NumPy

## Features
- Displays student information and marks.
- Calculates total marks and average marks.
- Assigns grades based on student averages.
- Identifies pass and fail results.
- Calculates class and subject averages.
- Identifies the top three performing students.
- Analyzes student attendance.

## Dataset
The dataset contains 15 student records, including student IDs, names, departments, subject marks, and attendance.

## How to Run
The Python program was developed and tested using an online Python compiler that supports Pandas and NumPy.

## Conclusion
This project demonstrates how Python, Pandas, and NumPy can be used to organize student data and analyze academic performance.
