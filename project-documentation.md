# Student Performance Analytics System

## 1. Project Title
**Student Performance Analytics System**

## 2. Objective
The objective of this project is to analyze student academic performance using Python, Pandas, and NumPy. It helps calculate marks, averages, grades, pass/fail results, subject-wise performance, and attendance statistics.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Online Python compiler

## 4. Dataset Description
The dataset contains 15 student records with the following fields:
- Student ID
- Name
- Department
- Python marks
- Mathematics marks
- Artificial Intelligence (AI) marks
- Attendance percentage

## 5. Implementation
The project uses Pandas to organize student information in a DataFrame and NumPy for numerical calculations.

The program performs the following operations:
1. Loads the student data into a DataFrame.
2. Calculates total marks and average marks for each student.
3. Assigns grades based on the calculated average.
4. Checks whether students pass or fail based on their subject marks.
5. Calculates the overall class average.
6. Identifies the highest and lowest student averages.
7. Calculates subject-wise averages and identifies the best- and lowest-performing subjects.
8. Identifies the top three performing students.
9. Calculates average attendance and lists students whose attendance is below 75%.

## 6. Key Features
- Student marks summary
- Automatic grade calculation
- Pass/fail analysis
- Class performance analysis
- Subject-wise performance analysis
- Top three student identification
- Attendance analysis

## 7. Output and Screenshots
Screenshots of the program output are included in the GitHub repository. They demonstrate the displayed student data and performance analysis results.

## 8. Final Outcome
The project demonstrates how Python, Pandas, and NumPy can be used to organize student data and perform basic academic performance analysis. It produces useful summaries that help identify high-performing students, subject averages, pass/fail counts, and attendance concerns.
